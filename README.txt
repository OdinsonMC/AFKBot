AFK Bot (Android) - builds an APK with GitHub Actions

1. Create a GitHub repo, upload ALL files of this folder (keep .github/workflows/build.yml).
2. Open the repo > Actions tab > "Build APK" > wait for the green tick.
3. Click the finished run > Artifacts > AfkBot-apk > download, unzip, send app-debug.apk on WhatsApp.
4. On the phone: install it (allow "install unknown apps"), open it, press
   "Allow running in background", then "Start bot".
